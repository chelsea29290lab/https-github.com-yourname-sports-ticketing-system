# 📖 Introduction

The Sports Ticketing System is a web-based platform developed to improve the ticket booking experience for sports events. Traditional ticket booking methods often face issues such as overcrowding, ticket fraud, and inefficient seat management.

This system provides:
- Online event browsing
- Real-time seat booking
- Secure authentication
- Booking management
- Admin event control
- Responsive user interface

The application follows a client-server architecture using modern web technologies including React.js, Node.js, Express.js, and MySQL.

# 🏗️ System Architecture

The Sports Ticketing System follows a three-tier architecture:

1. Presentation Layer (Frontend)
2. Business Logic Layer (Backend API)
3. Data Layer (MySQL Database)
